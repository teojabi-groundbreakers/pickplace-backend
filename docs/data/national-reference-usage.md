근거는 각 공식 `catalog/{ID}/fileData.json`의 license 및 제공기관 정보다. 지역 코드 목록의 본문은 우리가 사용한 [행안부 주민등록·인감 게시판](https://www.mois.go.kr/frt/bbs/type001/commonSelectBoardList.do?bbsId=BBSMSTR_000000000052)을 원문으로 연결하고, 현행·말소 포함 주소코드와 Layout을 설명한다. 단순히 인터넷에서 내려받을 수 있다는 이유로 허용 판정한 것은 아니다.

지역 목록의 alternateName은2022년 표제이고 메타 수정일은2025-09-22다. 개별20261026 ZIP에 공공누리 표시를 발견했다고 기록하지 않는다. 해당 공공데이터 목록이 안내하는 동일 원천 게시판·자료 종류의 연결을 대조해, 현재 기준정보의 서비스 이용 근거로 판단했다. 이 연결 및 판단 범위는 [원문 해시·검토 기록](national-reference-usage.json)에 남겼다.

## 적용 범위와 출처 표시

- 이번 적용은 지역 코드·명칭·이력 및 서비스용 업종 분류와 파생 선택 계층이다.
- 원본 ZIP/HWPX는 내부 검증용으로 보관하고 서비스나 GitHub에서 재배포하지 않는다. Layout은 파서 해석에 사용한다.
- 출처 기관·목록 링크·원천 기준일·가공 주체를 기록한다. 공식 기관이 PickPlace의 판단을 보증하는 것처럼 표시하지 않는다.
- SGIS·관광 데이터·지도·사진 등의 이용조건은 이번 판정을 적용하지 않는다.

표시 문구:

> 지역 코드: 행정안전부 주민등록업무 행정기관 및 관할구역(첨부20261026). 인구: 행정안전부 주민등록 인구(2026-09-30). 업소·업종: 소상공인시장진흥공단 상가(상권)정보(202609 배포본). 원천을 가공한 주체: PickPlace.

향후 FE/API 연결에서 각 화면·응답의 자료 기준 시점과 출처 안내를 반영한다. T07의 DB 게시 완료가 FE 화면 배포 완료를 뜻하지 않는다.

원문 보관: 작업공간 `data-validation/2026-11-09/t07-finalization/`. 자료별 metadata와 원문 연결 페이지의 SHA256을 검토 JSON에 기록했으며, 최종 묶음 준비 스크립트가 이를 다시 검사한다. 서비스 DB의 artifact.usage_evidence에도 목록·해시·연결 원천·이용 범위를 저장한다.
